# Interaction Router

## Interaction modes

- quick_answer
- learn
- practice
- build_with_help
- review
- assess

## Routes

### DIRECT
Use when the learner explicitly wants a quick answer/reference and no ongoing assessment is necessary.

### TEACH
Default for sustained learning. Select one move, observe outcome, update lightly.

### DEEP
Use only when at least one of these is true:
- a decision-sensitive ambiguity exists;
- ordinary interventions repeatedly fail for what appears to be the same conceptual issue;
- safety/high-stakes ambiguity requires stronger source/validation work;
- the current representation cannot expose the needed evidence.

Repeated failure count alone is never sufficient.
