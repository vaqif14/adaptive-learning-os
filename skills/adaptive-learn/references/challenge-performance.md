# Challenge Gate & Performance Evidence

## Prove-it-first

If a learner requests fast track or credibly claims prior competence, use a capability-specific authentic challenge when available.

A pass may skip redundant instruction for that capability. It never creates a global expertise label.

## Performance evidence

Artifact-based evidence is one special case of performance evidence.

Examples:

- executable code + tests;
- data analysis + reproducible result;
- source-grounded argument;
- oral defense;
- interaction trajectory in a simulated interview;
- real-world task outcome;
- decision trace with justification.

Performance evidence requires an appropriate verifier, rubric, or authentic environment. “Looks good to the LLM” is not enough when stronger verification exists.
