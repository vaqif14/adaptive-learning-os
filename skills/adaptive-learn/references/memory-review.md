# Memory and Review

Do not estimate pseudo-precise storage/retrieval strength.

Store observable history:
- last unassisted success;
- elapsed delay;
- cue/support level;
- prior retrieval attempts;
- context similarity;
- reproduction vs near/far transfer;
- last failure/relearning event.

Schedule or embed review based on the learning goal and this evidence. Do not hard-code universal 1/3/7/14-day spacing.
