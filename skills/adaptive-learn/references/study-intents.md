# Study Intent Catalog

Study Intents are routing semantics, not agents.

Core intents:

- `quick_reference` — concise fact/reference, no teaching ritual.
- `compress_source` — summarize/compress; never mastery by itself.
- `build_plan` — plan from goal/resources/deadline; plan output is not mastery.
- `learn_concept` — build independent capability.
- `decompose_task` — split a task into steps without claiming learning.
- `build_with_help` — co-produce with support provenance.
- `critique_artifact` — critique learner work, then require learner revision if learning is the goal.
- `interpret_question` — clarify what the task asks before diagnosing knowledge.
- `simulate_performance` — role/scenario simulation with fidelity limits.
- `practice_retrieval` — retrieval practice matched to capability.
- `deliver_artifact` — optimize delivery; never silently convert delivery into mastery evidence.

Goal mode is separate from Study Intent:

```text
learn
perform_with_assistance
deliver_artifact
quick_reference
```
