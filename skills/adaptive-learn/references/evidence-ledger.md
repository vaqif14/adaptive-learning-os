# Evidence Ledger

## Four layers

```text
Raw Event → Observation → Evidence → Projection
```

### Raw event
What happened, with minimal interpretation.

### Observation
A normalized description of behavior.

### Evidence
A claim-bearing record with provenance, independence, support, scope, and strength.

### Projection
A rebuildable learner-facing decision state.

## Evidence scope

- supported_completion
- independent_reproduction
- near_transfer
- far_transfer
- delayed_independent_performance

## Evidence strength

`strong`, `medium`, `weak` are qualitative labels, not calibrated probabilities.

Weak telemetry cannot create a stable learner claim by itself.
