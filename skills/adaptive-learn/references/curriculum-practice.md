# Curriculum Authority & Practice Coverage

## Curriculum Authority Gate

The LLM is a curriculum adapter, not the default curriculum authority.

Priority:

1. authoritative curriculum/spec/dependency graph;
2. adapt to learner mission and evidence;
3. if unavailable, research and triangulate before proposing sequence;
4. preserve uncertainty when prerequisite relationships are unclear.

## Practice Coverage

Avoid repetitive practice loops caused by LLMs generating the same surface form.

Track coverage dimensions such as:

- concept/subskill;
- context;
- surface form;
- error class;
- representation;
- difficulty;
- transfer distance.

Choose under-covered cells without changing the underlying target capability unnecessarily.
