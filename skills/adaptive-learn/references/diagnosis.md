# 3-Level Diagnostic Capability

## L0 — no diagnosis
Default.

## L1 — observable error class
Describe only what occurred.

## L2 — competing explanatory hypotheses
Only when the cause changes the intervention.

L2 proposal schema requires:
- hypothesis id;
- narrow explanation;
- predicted observation;
- discriminating probe;
- status=`tentative`;
- provenance;
- decision impact.

A hypothesis without a falsification/discrimination route is rejected.
