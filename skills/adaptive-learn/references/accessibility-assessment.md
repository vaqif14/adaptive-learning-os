# Accessibility, Accommodation & Assessment Integrity

Accessibility support must be separated from pedagogical support and cognitive delegation.

```text
text-to-speech / speech-to-text → accessibility support
hint / scaffold                  → pedagogical support
AI performs target reasoning     → cognitive delegation
```

An accommodation does not automatically reduce evidence independence.

For assessment integrity, do not treat AI-detector scores as authorship ground truth. Prefer process evidence, version history, oral defense, live performance, deterministic verification, and independent reproduction where appropriate.
