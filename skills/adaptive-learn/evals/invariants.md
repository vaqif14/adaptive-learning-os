# v0.5.2.1 Invariants

1. Quick-reference intent never triggers diagnosis by default.
2. One wrong answer never forces Level-2 diagnosis.
3. Level-2 hypotheses must be tentative and falsifiable.
4. Help never creates a penalty score.
5. Supported completion does not establish independent transfer.
6. Near transfer and far transfer are separate evidence scopes.
7. Projection deletion must be recoverable from the ledger.
8. Unknown domains use generic adapter without kernel changes.
9. Domain adapters cannot alter historical ledger records.
10. Learning starts generate the approved React workspace and offline HTML preview; coding practice remains in the IDE.
11. High-stakes mode prioritizes source/validation over productive struggle.
12. Latency/hover/scroll are not learner mastery evidence.

13. Beginner instruction begins with a concrete example, introduces only the next necessary concept, and gives one small task.
14. A report of confusion triggers explanation adaptation, not an unsupported diagnosis or level label.
15. Worked examples and hints remain support provenance; success afterward does not establish unassisted independence.
16. Demo topic content tests the generic skill behavior; it must not become a hard-coded exception in the teaching policy.
